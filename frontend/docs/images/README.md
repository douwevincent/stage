# Captures d'ecran - Documentation Frontend

Ce dossier contient les captures d'ecran a integrer dans la documentation utilisateur.

## Structure

- `manuel-complet/`: captures utilisees par `docs/manuel-utilisateur-frontend.md`
- `manuel-court/`: captures utilisees par `docs/manuel-utilisateur-frontend-court.md`

## Convention de nommage

- Prefixe numerique sur 2 chiffres pour garder l'ordre.
- Nom court et explicite.
- Format recommande: `.png`

Exemples:
- `01-login.png`
- `02-dashboard.png`
- `03-inscriptions-filtres.png`
- `04-inscriptions-modal-ajout.png`

## Recommandations

- Masquer les donnees personnelles ou sensibles avant diffusion.
- Utiliser une resolution homogene pour toutes les captures.
- Preferer une capture par etape critique (liste, modal, confirmation, message de succes/erreur).
