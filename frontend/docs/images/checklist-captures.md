# Checklist de session - Captures d'ecran

Objectif: produire toutes les captures necessaires en une seule session de recette, dans le bon ordre.

## 1. Preparation

1. Se connecter avec un compte de test (pas de donnees sensibles).
2. Regler le zoom navigateur a 100%.
3. Utiliser une resolution stable (recommande: 1600x900 ou 1920x1080).
4. Vider les notifications temporaires avant chaque capture non concernee.
5. Verifier que la date/heure systeme n'affiche pas d'information confidentielle inutile.

## 2. Regles de qualite

1. Une capture = un objectif lisible.
2. Inclure les elements utiles (titre, filtres, boutons d'action).
3. Eviter les popups parasites ou menus ouverts involontairement.
4. Masquer les emails, noms et matricules reels si necessaire.
5. Sauvegarder en PNG.

## 5. Controle final avant commit

1. Tous les fichiers sont presents et correctement nommes.
2. Les captures s'affichent dans les deux manuels Markdown.
3. Aucune donnee sensible non masquee.
4. Les captures sont nettes (pas floues).
5. Le cadrage est coherent entre ecrans (style uniforme).
